# App Inventory Exporter

[ English ] | [ Català ]

---

## English

A cross-platform GUI application (Linux, macOS, Windows) to export the list of installed applications and extensions on your system to Markdown (.md) format.

### Features
- **Cross-platform:** Compatible with Linux, macOS, and Windows.
- **Graphical User Interface:** Built-in GUI using Tkinter.
- **Configurable Frequency:** Set save frequencies according to your needs.
- **Multiple Destinations:** Export up to 5 synchronized copies to different directories or network shares (SMB).
- **Package Managers Supported:** Detects APT packages, Snaps, and GNOME extensions on Linux systems.

## Català
Aplicació GUI multiplataforma (Linux, macOS, Windows) per exportar el llistat d'aplicacions i extensions instal·lades al teu sistema en format Markdown (.md).

## Funcionalitats
- **Multiplataforma:** Compatible amb Linux, macOS i Windows.
- **Interfície Gràfica:** Desenvolupada amb Tkinter.
- **Freqüència Configurable:** Permet definir la freqüència d'execució.
- **Múltiples Destins:** Genera fins a 5 còpies sincronitzades en diferents rutes o unitats de xarxa (SMB).
- **Gestors de Paquets Suportats:** Detecta paquets APT, Snaps i extensions GNOME a sistemes Linux.
